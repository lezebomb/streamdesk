# StreamDesk 0.2.0 第一阶段

0.1.0 基线保留于 GitHub 提交 `3d5e178cc2c8189f44fec48193057a284d107cd7`。本阶段不改播放器核心或页面布局。

- Apple CMS 按 `vod_play_from` / `vod_play_url` 的 `$$$` 保留所有分组，分组内按 `#` 拆集。直接 HLS / MP4 与播放页面分别记录；页面不会被猜测为媒体链接。
- 同资源分组立即成为同集候选，其他来源逐个详情匹配。不同年份、季、解说/预告、上下半集不会自动互换。
- 搜索使用 NDJSON 逐源展示，并取消过期搜索；单源 8 秒、整轮 20 秒上限、并发 2。已有 JSON 接口保留供脚本使用。
- 清晰度列表按完整签名刷新，手动切换使用 hls.js `nextLevel`。实际视频尺寸与呈现帧率单独测量；清单码率和分片网络吞吐分别显示。
- 播放策略根据内存、省流模式、连接信息和已有实际分片测速选择缓冲预算，保留原有快进恢复和 `resumePosition()`。
- Apple CMS 解析/匹配、搜索消费、播放策略和可迁移数据格式已进入 `shared/`，Node 只负责受限 HTTP 与本地配置服务。
- 收藏/历史支持版本化导出和校验导入；旧版本 localStorage 键保留作为迁移回退。

验证：18 项单元/合同测试通过；原有 8 项浏览器端到端检查通过，包括真实出画、37 秒位置换源、启动/播放中故障恢复、收藏历史、移动布局与离线外壳。故障注入明确属于合成测试，替代线路使用真实媒体。

新增来源来自[光速公开帮助页](https://www.guangsuzy.com/help/)，已实际验证《流浪地球》和《流浪地球2》的浏览器解码、45 秒播放及未缓存快进。30 部作品共 5 来源的预检查已完成，光速 24 部有精确命中且首个媒体片段可下载；完整浏览器/长时结果将另行提交，预检查不计为实际可播成功。

Netflix / 爱奇艺 / YouTube 平台入口搜索按用户最新要求取消。未加入付费、鉴权或 DRM 绕过。
