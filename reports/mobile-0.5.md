# StreamDesk 0.5.0：Mate 60 补充实测

2026-10-13，真实华为 Mate 60，用户提供系统版本 4.2.0.220。浏览器 UA：HuaweiBrowser 17.0.8.310 / Chromium 132 / Android 12 / HarmonyOS。375×679 CSS 视口、DPR 3.25。没有安装 APK，也没有修改休眠、清除数据、设置浏览器豁免或接触其它应用。临时页面唤醒锁在测试结束后释放。

手机通过 ADB reverse 连接电脑 Node 服务（4191）；目录 / 搜索仍由电脑服务提供，媒体 HTTPS 由手机直接下载、解码。不是“手机独立运行后端”测试。版本的播放器、hls.js ABR、增强核心没有因为这轮验证被重写。

## 搜索、筛选与实机操作

电影首批 467 ms、目录完成 6.66 s，实际 48 项。类型“动作 + 剧情”AND 交集有 45 项，重复点击取消成功。没有页面横向溢出；筛选可横向滚动，截图无黑色滚动条。年份为真实当前年 2026 到 2017，未出现 2027 / 2028。

“怪奇物语4”首批 2.22 s、完成 7.87 s；真实第四季第一，第一 / 二 / 三季也出现，共 11 项相关结果。“我们怎么可能成为恋人不行不行”首批 2.21 s、完成 5.91 s，匹配已核对的 2025 版。搜索中图标与文字都在实际请求过程中显示。导航选中背景 rgb(36,110,121)、文字白色，实机可清楚区分。

实际手机浏览器触屏事件验证：双击暂停和继续、右侧长按 2×、松手恢复原 1.25×、touchCancel 恢复原速度全部通过。应用提供的容器全屏也验证了进入后继续播放、长按 2× / 恢复 1.25×、双击暂停。第一次全屏脚本误用旧首帧指标，在新影片的异步详情还没加载完时就操作，长按未生效；失败截图保留，改为等待正确作品实际出画并正在播放后复测通过。没有为此改动播放器。使用手机上的实际引擎、屏幕和视频解码，不是电脑 viewport 模拟；浏览器自己的原生视频全屏不等同于应用容器全屏。

## 三类正片与恢复

均按 canonical ID / 年份挑选如意的正片，不把预告、解说或续篇当命中。下表首帧是 Player.load 开始到实际视频帧，**不包含准备搜索与详情时间**；准备搜索的实际 API 延迟分别为动漫缓存 25.70 ms、电影 5.58 s、剧集 7.21 s。原始分片 bytes / ms 单独记录于本地 JSON，公开汇总保留数值而移除媒体 URL。

| 正片 | 实际解码尺寸 | 首帧 | 跳到未缓冲 600 秒的首个恢复帧 | 观察 |

三部都有真实解码帧；普通观看各约 20 秒、快进前都未记录卡顿。但剧集第一次“快进后两秒内前进至少一秒”的严格观察没有通过，失败 JSON 保留：aborted（跳转时取消旧请求）与 bufferStalledError。不能因为 seeked / 一个恢复帧到达就宣称后续稳定。对同一剧集另一次 900 秒跳转实际继续前进到 902 秒，记录恢复 32.30 ms、零卡顿；该次已有预取，不与上表冷快进混作加速结论。测试脚本以后在 20 秒内核验继续前进，并仍保存卡顿。

手动切到暴风备用：第四季第一集保持，进度差约 2.69 秒，备用首帧 2.03 s。故障注入：只拦截当前如意媒体主机，注入测试 HTTP 404；真正备用线路接到第四季同一集，1 次换源，1200 秒目标恢复到 1202.99 秒，备用首帧 2.45 s。六次拦截记录是人工故障，不是源服务器真实返回 404。

上述只支持“样本可播、关键恢复路径可用”。等待表现提示缓冲不足，仍不能凭这些记录唯一归因到源服务器、网络或播放器；没有绕过 DRM、鉴权或媒体访问限制。

## 10 分钟持续播放

如意的 2025 动漫正片第 1 集，增强关闭、自动换源关闭以观察单条线路。按已有历史从约 610.74 秒继续，首帧 6.77 s（含恢复历史位置的加载；与从头播放不同）。

观察 **604.55 秒**，媒体进度前进 **604.55 秒**。14,490 次视频帧回调、0 掉帧、0 卡顿、卡顿时间占比 0、无播放器错误；缓冲约 60 秒，页面保持可见，临时唤醒锁没有被释放。不是整集、24 小时或全部片源的稳定性保证。

电池温度采样 32–33°C，系统总体 Thermal Status 为 0。华为浏览器**主进程** CPU 样本 3.5–86.2%（100% 约为一个核；不是所有子进程合计），PSS 609,716–654,466 KiB，约 595–639 MiB。这些数字包含浏览器自己的其它标签与服务，不能称为 StreamDesk 独占占用。thermalservice 个别传感器值可能是缓存；本报告不把它们当可靠芯片温升曲线。USB 充电使耗电量不能准确比较；没有 GPU 利用率计数器，因此未编造 GPU 占用、功率或续航数据。

## ABR、云同步与边界

公开 Mux 多码率流只临时用于播放器验证，不加入普通片库 / 收藏 / 历史。第一次手动 720p 后发生持续缓冲超时，失败截图保留；该次未完整抓到原始指标，根因仍未确定，不能推定纯网络问题。单独复测成功：清单真实提供 184 / 288 / 480 / 720 / 1080p，实际解码到 720p，手动切换的 7 秒观察内额外卡顿为 0，恢复自动档成功，增强保持 off。一次复测成功不抹除先前失败，也没有虚构 4K。

用户自己输入密码，真实手机和用户已登录的 Edge 页面确认：电脑已有的动漫收藏到达手机，手机产生的三部影片历史到达电脑；例如第四季第 1 集显示 20:04。Supabase 项目仍为 Free；不读取密码、会话令牌或复制登录凭证。测试发现工具另开匿名桌面标签页时容易误认用户未登录，后来选中用户原有标签页并关闭重复页；没有要求用户再次设置密码。

DLNA 扫描有界返回，未发现接收电视。Huawei Browser 未提供 Remote Playback API。只能确认入口、扫描和无设备提示正常，不能确认电视出画或“所有电视兼容”。
