# StreamDesk 0.2.0 实测报告

测试日期：2026-10-12；Windows / Node v24.13.0 / Chrome 154.0.8037.99。

## 结果与测试口径

31/31 部作品至少一个来源通过真实解码、45 秒持续播放、未缓存位置快进及恢复后 6 秒观察，共 33 次成功线路验证。电影、电视剧和动漫均包含新旧作品。测试每部作品的第一集/正片，不代表全部剧集或全天候稳定。

API 计时和媒体下载分开记录。首次出画从 Player.load 开始到 requestVideoFrameCallback 第一帧，不含详情 API；快进恢复从 seeking 到恢复后第一帧。卡顿率 = waiting 时长 / 播放观测时长；快进定位、主动暂停与页面隐藏不计为卡顿。

媒体预检查最多 2 个直接分组，每个请求 8 秒，首片最多读取 10 MiB；API 并发 2，浏览器逐部并发 1。长时测试与覆盖测试部分同时运行；测速不是独占线路容量。60 秒元数据缓存可能命中，API 均值不称为冷启动。

## 长时、画质与恢复

- 《爱情公寓3》第一集：连续 30.10 分钟，真实媒体推进 1806.04 秒，0 次 waiting 卡顿，卡顿累计 0.00 秒；关闭自动换源以隔离单源稳定性。
- 真实故障：《流浪地球》暴风失效后自动切光速，打开到备用第一帧 11.29 秒，保留 37 秒位置；恢复后记录 40.91 秒。不是合成故障。
- Apple 官方 AV1 测试流实际解码 3840×2160、约 23.98 fps；手动 HLS 切换的卡顿增量 0，随后切影片成功重置为自动。该 4K 结论只适用于公开测试流与当前设备，未发现 4K 时没有伪造档位。
- MediaCapabilities 的 supported/smooth/powerEfficient 是能力提示，无法确定实际硬件解码器。Android/HEVC/Media3 与安装更新尚未实机验证。
- ABR 以 CDP 模拟带宽上限验证，模拟链路上限不是实测线路带宽。见 abr.json 的实际级别和播放推进。

## 首测与追加复测

原 31 个查询的首测 26/31 部通过。首测文件和失败截图未修改。追加复测单独存放于 reports/runs/followup-2026-10-12：

- 星际穿越：来源使用“原声版/普通话版”标题，补充经公开 API 核实的别名。
- 西游记：1986 年资源使用“86版”标题，与 2012/1996 等版本明确区分。
- 女友的朋友：原计划类别误填电视剧，来源元数据为 2026 日本动漫；修正后复测，未把最初错误隐藏。
- 进击的巨人：明确匹配 2013 第一季，不能把最终季当成同集备选。
- 狂飙：第一页被相关短剧占满；搜索在缺少同名字面命中时最多继续 3 页，受整轮 20 秒截止约束。

0.1.0 的报告保留为 performance-0.1.md，其精选样本只观察约 12 秒。旧版与本次作品、网络负载和时长不同，不计算虚假的首帧提速百分比。

## 失败归因

- baofeng：HTTP 404 × 25。
- liangzi：HTTP 404 × 25。
- feifan：HTTP 403 × 24。
- guangsu：本次首片预检查未发现错误。
- wujin：HTTP 403 × 24。

明确的 HTTP 403/404/5xx 属于上游媒体请求失败；403 的具体授权/地域/策略原因未推断。浏览器 CORS 经常只暴露 status 0，需结合同 URL 的原始 HTTP 证据；单纯 timeout/fetch failed 无法在网络与服务器之间确定归因。缓冲足够却无帧可提示解码停滞，本次未证明存在此类实际故障。应用控制台未见异常。

## 复核补充

《进击的巨人》首次追加测试实际已恢复出画，但脚本误用了启动时间对齐产生的 seek 计数，恢复后只观察约 1.5 秒而造成假阴性。等待新增 seek 事件后再观察 6 秒的确认结果位于 reports/runs/seek-confirmation-2026-10-12；原失败文件不改写。

完整 videolist 记录可以复用详情：爱情公寓3 搜索 2116 ms，已缓存详情处理 2.62 ms，24 集。此数值是本地缓存处理时间，不是源服务器网络响应时间；此前覆盖实测 API 均值未重新换算。

升级验收：0.1.0 格式的爱情公寓3 第2集历史，37 秒位置，经真实媒体加载后保留为 season:3:episode:2，继续到 40.90 秒；收藏保持。最终单元/合同测试 27 项、原有端到端 8 项、新分组/渐进式测试 3 项均通过。回归期间保留过源访问链导致的换源失败记录，已修复手动选线后可重新回到健康备用线路。
