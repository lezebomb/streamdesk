验证日期：2026-10-12 至 2026-10-13，Asia/Shanghai。基于 0.3.0 的实际播放核心迭代。机器网络、CDN 时段、缓存和同时进行的验证会影响结果；以下为观测值，不是永久稳定性保证。

这 12 部覆盖 8 部动漫、电影及剧集：指定的恋人动漫、葬送的芙莉莲、鬼灭之刃、胆大党、间谍过家家、轻音少女、天官赐福、凡人修仙传、流浪地球、漫长的季节、灌篮高手、爱情公寓3。与前轮 34 部作品有重叠，不把两组数量直接相加。前轮 31/34 部真实检索与播放证据完整保留，不重复执行整个大矩阵。

两站都有指定动漫 2025 正片的可用 1080p 媒体。ikun 的流浪地球为 1280×504、爱情公寓3 为 1280×720；魔都的流浪地球特别版为 1920×758、葬送第二季为 1920×1080。特别版与普通版内容节奏可能不同，保留秒数不代表逐帧一致。未把缩放画面称为原生 4K。

六个代表场景各观看 30 秒后跳至未缓冲的 600 秒位置，再验证真实帧前进。快进恢复：ikun 0.66–0.74 s，魔都 0.44–0.82 s。短场景只证明核心播放与快进路径；持续稳定性使用独立长时记录。

API 响应时间与媒体下载的 TTFB、字节、吞吐分开保存在 reports/runs/expansion-0.4/search-media.json。真实分片成功不等同于已解码成功。每条成功或失败均留 JSON / 截图 / 清单证据，汇总见 experience-summary.json。

ikun 分发经过 bfikuncdn.com / kkzycdn.com，魔都经过 play.modujx11.com / bf.modujx11.com 等路径；它们可作为不同媒体路径的备用来源，但不能证明运营方或元数据供应链相互独立。

## 持续播放

指定恋人动漫在 ikun 单源、关闭自动换源与增强条件下播放 **601.54 秒（10.03 分钟）**，媒体实际前进 600.02 秒，14,374 个呈现帧，0 掉帧、0 卡顿事件、0 ms 卡顿时间。本轮不能据此宣称所有线路整集或整部电影稳定。0.3 的 30.12 分钟成功和 12.37 分钟真实失败仍见 performance-0.3.md，失败未删除。

## 搜索、筛选与界面

已用实际 API 验证“怪奇物语3”得到“怪奇物语 第三季”，搜索中有旋转图标，候选按相关性排列。每来源最多 3 个 API 请求，整体截止 20 秒，并发 2；慢源不阻塞已到结果。年份、季数和 OVA / 正片匹配仍是换源约束。

未来年份、无效日期标为待核实；尚未上映的日期与影片上传时间不进入近期推荐。来源元数据仍可能有其他错误，不能宣称全库已逐一核对。近期推荐读取实际目录，先限制有效近期上映，再依据上映时间和来源热度排序，没有编造固定热榜。

[Apple CMS 上游实现](https://github.com/magicblack/maccms10/blob/master/application/api/controller/Provide.php)提供 year 与年份范围参数。普通请求逐站核实：暴风、速播、魔都、ikun 均返回正确的 2009 年与 1900–2015 范围；光速与红牛会忽略年份参数，未声称它们支持原生年份过滤。类型 / 语言优先选择 API 返回的匹配子分类，并对数据再次过滤。高分针对已载入结果排序，滚动可继续加载；不是完整全网排行榜。

豆瓣页面普通访问返回 403，本轮没有绕过限制。显示的评分取明确的 vod_douban_score 且需有效豆瓣 ID，来源自己的 vod_score 不冒充豆瓣。界面标注其为来源提供的豆瓣评分；未实时核验其准确性。

首页 / 我的、分类筛选、单条最近观看与全部历史、收藏、选集与线路均接入真实数据。默认界面移除测试目录、来源勾选、性能报告及诊断。筛选栏可滑动，无可见横向滚动条，随页面向上滚走。没有加入应用广告；来源视频自身可能有嵌入内容。

## 桌面核心验收

42 项单元 / 合约检查通过。实际浏览器端到端通过多来源播放、未缓存快进、手动换源保持进度、收藏 / 历史重启恢复、注入 HTTP 404 后换到真实备用媒体、手机宽度无横向溢出和离线外壳。隔离外网 smoke 通过，独立记录为非媒体测试。

experience.mjs 通过真实季数简称搜索、加载图标、隐藏异常年份、无滚动条但可滑动、触摸覆盖层双击 / 长按临时 2× 并恢复原 1.25×。最后下载 **71,881,834 字节**的完整开放电影 HLS，在断网后从我的下载打开并解码、继续呈现真实帧。这次公开电影用于下载技术验证；影视覆盖结论来自上面的实际作品。

Blender 公开 MP4 允许视频播放，但浏览器跨域读取失败，因此不能下载进应用缓存；失败记录保留。未关闭浏览器保护或添加伪造请求头。当前下载支持允许浏览器读取的 MP4 和完整、未加密、非范围分片 HLS，单集上限 320 MiB。尚未测所有格式、浏览器存储驱逐和跨设备迁移下载数据。

## 手机与投屏

Mate 60 / 4.2.0.220 / Huawei Browser 17.0.8.310 实机已验证动漫别名检索、分类 / 筛选、1920×1080 播放，首帧 8.08 s，未缓冲快进恢复 1.06 s。旧实现的双击暂停和右侧长按未通过，结果保留。后来加入触摸覆盖层并通过桌面触摸模拟，**修复后的 Mate 60 实测尚未完成**。用户随后断开手机并要求先做其他工作，本轮没有补造手机数据。

华为浏览器未暴露 Remote Playback API。DLNA 发现 / SOAP 播放控制与浏览器原生入口已实现，但本轮发现 0 个真实电视接收器；不能宣称电视实机出画或所有电视兼容。仅控制刚发现的局域网接收器，描述及控制地址限制到同一设备 IP，响应、时间、并发均有上限。Embed、受保护视频和部分电视不支持的 HLS / 编码仍不能直接投屏。

没有修改手机系统设置、安装 APK、清除数据或关闭其他设备服务；测试页临时唤醒锁在结束时释放。旧截图采集方法和缓冲限制导致的工具失败，也保留为工具故障而非片源故障。

## 失败审计与未重复项目

初次 ikun 爱情公寓3 测试脚本使用了错误预期豆瓣 ID，出现“Exact identity missing”；核对真实 API 得到 douban:6312211 后单独重测通过，初始失败文件保留。该故障不计为片源不可播。

第一影视候选接口明确返回不支持搜索，未加入默认配置。yuny.tv 普通请求证书域名不匹配，未关闭证书检查；动漫共和国所查页面为应用宣传页，未发现可核实公共媒体接口；FrameXTV 的既有 Embed 记录不能提供直接播放控制，本轮未当作成功新媒体来源。

画质增强按用户要求停止继续调整，保留 0.3 的 Intel / RTX / Mate 60 测试与算法限制。本轮不重复 GPU、发热、功耗与原生 UHD 全矩阵，也不重新跑 34 部作品的所有组合；重点验证新增来源、搜索问题、数据保留、下载、故障换源和界面。手机、实际电视、客户端打包与更新尚未验收的部分清楚保留，不宣称完成。
