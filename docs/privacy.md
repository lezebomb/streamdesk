# 个人数据边界

服务只绑定电脑回环地址，验证请求 Host、Origin 与跨站标记。手机网页验证使用指定端口的 ADB 反向转发，不将 Node 服务开放到局域网。没有用于外网访问的通用代理；来源请求只去本机配置的公开 API，拒绝内网地址、跨站重定向及过大响应。

`/reports/`、`/data/`、环境配置和 Git 路径不可通过服务读取。前端来源列表不返回 API 配置地址；播放时需要的媒体地址仍会交给播放器。本地浏览器与系统管理员可以检查自己电脑上的请求，这些措施不提供匿名性。

源配置、目录缓存、云配置、个人截图、观看及测速证据只保存在本地，被 `.gitignore` 排除。公开代码与分发包经过同一公开文件白名单检查。GitHub 已有历史提交中出现的旧资料仍可被读取；本轮删除公开树中的资料不会重写历史。

收藏与历史同步使用 Supabase 所有者 RLS，客户端只有 publishable key，没有服务端管理密钥。账号会话由 SDK 管理；密码和确认链接不写入诊断文件。视频文件与来源配置不上传至云库。更新程序必须保留应用数据目录，不通过卸载旧版更新。
