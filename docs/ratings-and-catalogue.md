# 目录、筛选与评分

目录使用本地持久作品索引，播放地址按需从私人来源读取。类型多选取交集；语言按明确音轨字段或配音版本过滤，地区分类不代表音轨。年份使用发行年份，不使用上传日期。未核实的字段不猜测。

近期推荐排除赛事、解说、预告、短剧、明确标注的 AI 制作内容；动漫推荐要求日本地区依据，中国动画不进入首页推荐。影片分类、季数、版本身份相互独立。新到的来源结果不会替换已经显示的海报。

`sourceRating` 保存资源站的 `vod_douban_score`、提供者、声称的豆瓣条目与观察时间，始终属于未核验数据。`doubanRating` 单独保存正常读取豆瓣页面得到的评分、评价人数、条目、核验时间及片名、年份、类型、季数身份。旧备份中的 `doubanScore` 只能作为未核验缓存显示，不能升级为核验评分。

评分绑定必须同时匹配片名、年份、季数及类型；来源声称的条目 ID 不能覆盖身份冲突。数字与中文季数可以等价，续集电影不能当作电视剧季数。无法确定的评分不绑定。高分排序优先核验评分，片源评分与无评分条目随后列出。

搜索和目录查询不等待外部评分服务。可见卡片最多 12 条一批，只读取本地评分缓存；打开影片后独立核验评分，不等待核验才播放。外部评分最多占一个网络槽，搜索保留两个槽并优先调度。每分钟最多为两个新作品发起详情核验；同作品请求合并，拒绝访问、限流与失败采用退避。缓存标注核验日期，超过七天明确显示缓存来源。

公开榜单仅用于作品目录与评分，不证明存在可用媒体，也不是完整全网影片库。目录影片点击后按严格身份匹配本地配置来源，找不到媒体时明确提示。普通访问被拒绝就停止；没有共享账号、借用第三方密钥、伪装鉴权或 DRM 绕过。

`npm test` 包含评分错季、错年、同名、错类型、来源分离、限流缓存回退和后台请求不阻塞搜索的测试。真实作品及设备证据保存在本地 `reports/`，不进入公开仓库或应用分发包。
