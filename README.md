# StreamDesk 0.4.1

个人影视 PWA：多来源搜索、选集播放、自动换源、画质选择、收藏、观看历史与离线下载。页面采用首页 / 我的两个入口，支持手机三列海报和电脑布局。

0.4.0 在已验证的 0.3.0 播放核心上迭代：增加魔都、ikun，补充动漫别名与季数简称搜索，显示搜索中图标，增加分类与类型 / 语言 / 年份 / 最新或高分筛选。普通界面不显示来源勾选、性能诊断、报告或公开测试影片。画质增强维持现有能力，默认关闭。

“怪奇物语3 / 第3季 / 第三季 / S03”支持等价检索，按相关性排序。换源仍严格核对作品、年份、季数、集数与 OVA / 正片身份。异常未来年份标为待核实；未来上映日期及上传日期不会被当作近期上映。

近期推荐从来源实际目录读取，以有效上映日期或有效年份筛选近期作品，并参考来源提供的热度；没有静态编造的热榜。豆瓣评分来自 API 的明确豆瓣字段，不把来源自身用户评分冒充豆瓣评分。本轮豆瓣站点返回 403，不能宣称评分已实时核对。

## 启动

```powershell
npm ci
npm test
npm run build
node server/index.mjs
```

打开 http://127.0.0.1:4173 。需 Node.js 24。交付 ZIP 含已构建 dist，可双击 Start-StreamDesk.cmd，无需安装 npm 运行时依赖。GitHub 源码需先构建。

升级时保留 data/sources.json，使用原来的端口与浏览器，以保留收藏和历史；我的页面可备份、恢复记录。默认验证来源自动合并，不覆盖其他私人配置。测试目录仅在显式指定 STREAMDESK_SOURCES 时使用。

## 验证与边界

- [0.4 性能与失败证据说明](reports/performance.md)、[汇总数据](reports/experience-summary.json)、[复现命令](docs/validation-0.4.md)。0.3 原始结论见 [归档报告](reports/performance-0.3.md)。
- 新来源进行 12 部作品的搜索 / 分片检查、6 个代表场景实际解码和快进；另有 10 分钟连续播放。分片成功不等同于完整观看成功。
- 来源分类与分页驱动目录。已验证四个来源支持指定年份与年份范围；语言和类型优先选择匹配的分类，最终按返回元数据过滤。高分排序作用于已载入的结果，继续滚动可扩大目录，不能宣称全网完整豆瓣榜单。
- 离线下载支持允许浏览器读取的 MP4，以及未加密、非范围分片、完整结束的 HLS；单集上限 320 MiB。下载需 Service Worker 与足够存储空间，失败会清理本次残留，不删除已完成下载。已验证完整 HLS 下载后断网解码。部分 MP4 来源允许播放但禁止跨域读取，不能下载，不改请求头或关闭浏览器保护。
- 手机双击与右侧长按使用触摸覆盖层。桌面触摸模拟通过；Mate 60 的修复后实测待手机重新连接。普通原生视频全屏、浏览器自带视频助手可能有不同的行为。
- 手机投屏提供 DLNA 发现 / 控制与浏览器原生入口。Mate 60 华为浏览器未提供 Remote Playback API，本轮未发现真实 DLNA 电视。未宣称所有电视兼容或电视实机出画已验证；服务端只控制当前发现的局域网接收器，不接收任意控制 URL。
- 当前仍是电脑 Node 服务 + PWA；没有独立 Android APK、Windows 安装器或自动更新。手机独立运行的架构说明保留在 [客户端方案](docs/clients-and-updates.md)。

## 测试

```powershell
npm run test:smoke
npm run test:package
```

真实媒体、桌面体验、长时与手机复测命令见复现文档。CI 在 Windows / Linux 检查单元测试、构建、完整运行包，另跑隔离外网的浏览器 smoke；不把离线模拟测试当成真实媒体数据。

适配器入口为 shared/source-adapter.ts 与 server/adapters.mjs，复用 LibreTV 解析与恢复核心、hls.js。只使用已返回的公开媒体地址；Embed 保留来源自己的播放器，不假定能读取内部播放进度、ABR 或 DRM 状态。许可证和上游署名见 THIRD_PARTY_NOTICES.md。

0.4.1 修正“更早”筛选的年份边界：当前列出 2026–2017 时，更早包含 2016 及以前。原始媒体实验版本为 0.4.0，播放器和界面布局未因本补丁改变。
